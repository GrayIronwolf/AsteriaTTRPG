# Phase 3.9 — Five remaining physical Dice Towers

**Branch:** \`Website-Build-Test\` only. **Deployment:** none.

Six catalogue families now share one validated local schema and the same single
Three.js/Cannon worker-compatible prediction pipeline. Phase 3.9 adds:
Dragon, Wizard, Dwarven Forge, Nature and Celestial to the existing Castle Tower.
Each has standard / detailed / grand geometry variations.

The THREE components are genuine PBR meshes. Their bodies are visually distinct:
- Dragon: horned head, scales, membrane wings and a mouth-style entrance/exit.
- Wizard: pointed spire, magic rune windows, banners and luminous roof crystal.
- Dwarven Forge: riveted forged iron, animated-looking static gears, pipes, anvil and glow.
- Nature: irregular hollow-tree columns, bark, leafy branches and root railings.
- Celestial: marble/gold columns, luminous floating crystal, arches and star detailing.

The only colliding surfaces are those explicitly shared between THREE meshes and
Cannon static box bodies, including physical baffles and the exit ramp. Distinct
family/variation layouts make bounded physical adjustments to the tuned Castle base.
Decorations cannot secretly redirect physics.

The optional test-side appearance studio exposes all confirmed material/colour, trim,
motif, lighting, wear, quality and paired-tray settings; these are **local-only**.
No unreviewed tower data is written to the Phase 3.7 saved-collection schema.

All towers are **experimental until** (a) their physical browser verification
passes, (b) 100+ actual multi-type physical stress runs are completed including
the Phase 3.8 gate, and (c) the owner approves release. No hidden production enablement.
