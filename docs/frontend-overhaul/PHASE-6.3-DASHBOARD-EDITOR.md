# Phase 6.3 - React/Vite Dashboard Editor

Reuses existing v4 dashboardLayoutModel and 12-column geometry, sizes, focus snapshots, presets, locked positions and viewportLayouts. Per-GM layout persists at users/{gmUid}/dashboardLayouts/gm-{campaignId}. Per-player layout persists in dashboardPreferences on the owner record and its approved campaign-linked character. Save transactions require fresh ownership and v1/v2 membership and reject conflicting revisions. Editor provides drag/resize snapping, panel toggles, locked positions, undo/redo, per-viewport reset confirmation, and scoped styles. Unmigrated gameplay panels show pending content rather than mounting legacy code. Both dashboards remain disabled for editor writes until VITE_ASTERIA_DASHBOARD_EDITOR_ENABLED=true; production build and deployment are unchanged. Phase 6.4 handles maps and presentation; Phase 7 handles gameplay commands.
